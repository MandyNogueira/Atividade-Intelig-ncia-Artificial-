# Trabalho de NLP e Visão Computacional

Este repositório contém a implementação de algoritmos fundamentais em Processamento de Linguagem Natural (NLP) e Visão Computacional, desenvolvidos como parte dos requisitos avaliativos da disciplina de Inteligência Artificial.

# Técnicas escolhidas

- Tokenização
- Filtro Gaussiano

# Descrição do Projeto

O objetivo deste trabalho é demonstrar a aplicação prática de conceitos teóricos abordados em sala de aula, divididos em dois pilares principais:

# 1. Processamento de Linguagem Natural (NLP)

* **Tokenização:** Implementação de rotinas para segmentação de strings em tokens, permitindo a análise individual de elementos linguísticos.
* **Análise de Texto:** Estruturação de dados textuais para processamento subsequente.

# 2. Visão Computacional

* **Suavização de Imagem (Filtro Gaussiano):** Aplicação de uma função gaussiana para a redução de ruído e filtragem de frequências espaciais em imagens digitais.

#  Tecnologias Utilizadas

* **Linguagem:** Python 3.x
* **Bibliotecas Principais:** * `OpenCV` (Processamento de imagem)
* `NLTK` ( biblioteca usada para Tokenização)

# Instruções para Execução

Para replicar os resultados apresentados:

1. Clone ou baixe este repositório.
2. Instale as dependências via terminal:

"pip install -r requirements.txt"

3. Execute o script de processamento:

"python filtro_gaussiano.py"
